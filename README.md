# Atividades da Faculdade – Engenharia da Computação

Repositório com as **resoluções das atividades práticas** das disciplinas envolvendo desenvolvimento de software, desenvolvidas ao longo das aulas/períodos.

## Objetivo

Centralizar e versionar os códigos produzidos na faculdade, funcionando como portfólio acadêmico e material de consulta para revisão dos conceitos estudados.

## Organização

Cada atividade fica em sua própria pasta, contendo o **enunciado** (`README.md`) e o **código-fonte** da resolução. A numeração segue a ordem cronológica das aulas.

## Tecnologias

- **C** e **C++**
- Compilação via **GCC / G++**

>Caso queria executar algum código em sua máquina, deve-se instalar o compilador e executar o seguinte código via terminal:

```bash
g++ arquivo.cpp -o programa && ./programa
